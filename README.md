fetcher.sh provides a unified web‑data API that aggregates public data from eleven major platforms—including Twitter, YouTube, TikTok, Instagram, Reddit, Google Search, Google Maps, Google News, Google Play, App Store, and Yelp—into a single, no‑account, pay‑per‑call interface. Users can retrieve up to 111 endpoints across these services without OAuth or subscription, paying only per request in USDC (≈ $0.002–$0.005). The service is built on an MCP server architecture, offers transparent pricing, and publishes full OpenAPI 3.1 specifications. Documentation, pricing, and a blog are openly available.

**Areas:** Company · Web Data · API Aggregation · No Auth · Pay per Call · MCP
